# clausewindow — static review

## Scope and verdict
Reviewed public `knarayanareddy/clausewindow` at **7adf12808884906cc85855bf9658e3a08f96e663**. This is a Python implementation/prototype, not an established legal-review service. The inspected API exposes contract review and persisted receipts, but application-level receipt access controls and complete extraction require attention before handling confidential agreements. Neither legal accuracy nor privacy, production readiness or compliance is established. **Runtime NOT RUN.**

The collected tree is not truncated: it contains `clausewindow/`, fixtures, two test files and a specification; it has no root `main.py`, package `__main__.py`, workflow, lockfile or separate web template. This is a tree inventory, not a full source audit. The API and PDF paths below were read; storage and playbook implementation were sampled, not comprehensively audited. No target software was installed or executed.

## Findings ledger

**F01 — Medium, confirmed static: broken onboarding.** [README.md:20–27](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/README.md#L20-L27) instructs `python main.py demo` and `python main.py serve`; the complete tree contains no root `main.py`. A new operator cannot follow those commands at this revision. Establish the intended entry point and smoke-test the documented instructions in an isolated environment.

**F02 — Medium, confirmed static: CI badge does not correspond to a committed workflow.** [README.md:3](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/README.md#L3) references `actions/workflows/ci.yml`; the complete pinned tree has no `.github/workflows/ci.yml`. Collected recent Actions runs are empty, with no collection error; this does not establish that no run ever existed. Remove the badge until a real gate is available, or implement and observe that gate.

**F03 — High consequence, unverified risk: sweeping legal and injection claims.** [README.md:7–9](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/README.md#L7-L9) says `Decision support only` but also claims it `eliminates RAG blind spots` and intercepts adversarial injections. The route labels its engine deterministic, not a demonstrated long-context model. Tests of model values cannot establish legal recall or injection immunity. Replace absolutes with measured scope, evaluate blinded cases with lawyers, and preserve human accountability.

**F04 — High, confirmed static: receipt API has no application-level access control.** [api.py:1019–1071](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/clausewindow/api.py#L1019-L1071) defines list and individual receipt routes without identity or authorization parameters; the list returns stored receipts. The [receipt payload](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/clausewindow/api.py#L343-L378) includes `findings`, `redlines`, filename and playbook snapshot. Anyone able to reach these routes may obtain sensitive information absent an effective external access boundary; an external gateway was not inspected. Require authenticated identity and ownership checks on every relevant route before shared deployment, with cross-tenant negative tests.

**F05 — High, confirmed static: partially empty PDF pages can be silently accepted.** [pdf_engine.py:624–636](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/clausewindow/pdf_engine.py#L624-L636) maps `extract_text()` returning `None` to an empty page, while [pdf_engine.py:663–679](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/clausewindow/pdf_engine.py#L663-L679) rejects only if the joined text is entirely blank. Thus a mixed scanned/text PDF can proceed without content from one or more pages; a genuinely blank page is also possible. Flag page-level extraction gaps and require manual assessment or verified OCR rather than asserting complete review.

**F06 — Medium, confirmed static: UI advertises YAML without a declared YAML dependency.** The fallback form says [api.py:169–171](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/clausewindow/api.py#L169-L171) `JSON or YAML playbook`; the [loader](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/clausewindow/playbook_engine.py#L691-L700) rejects non-JSON when YAML support is unavailable, and the full [manifest](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/pyproject.toml#L1-L26) does not declare PyYAML. An incidental environment may provide it, but clean-install YAML support is not ensured. Either declare and test safe YAML support or narrow the UI.

**F07 — Medium, confirmed static: signing is optional and not proof of lawyer identity.** [storage.py:522–530](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/clausewindow/storage.py#L522-L530) permits a missing key; [storage.py:569–582](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/clausewindow/storage.py#L569-L582) then returns no HMAC. Its [sign-off validation](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/clausewindow/storage.py#L1083-L1095) checks that the `actor` field is `human` and that `signer_id` is nonempty; neither proves identity or qualification. Do not present a hash chain or self-asserted role as independently authenticated legal approval; decide key custody and qualified reviewer verification.

## Five-discipline assessment

**Correctness / code review.** The API keeps extracted Unicode offsets and hashes in document metadata ([api.py:302–322](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/clausewindow/api.py#L302-L322)); PDF hashes are of extracted text ([pdf_engine.py:677–695](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/clausewindow/pdf_engine.py#L677-L695)), not necessarily original file bytes. Determine which identity the audit requires. F05 directly affects completeness; actual rule recall, cross-references and false positives remain unknown.

**Automation / testing.** The [model tests](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/tests/test_models.py#L59-L80) assert rejection of invalid spans; the [migration test](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/tests/test_storage_migration.py#L35-L80) checks columns, receipt readback and audit-chain verification. These are useful intent, not observed passes or proof of end-to-end legal coverage. No test runner or CI was executed.

**DevOps / operations.** [api.py:280–299](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/clausewindow/api.py#L280-L299) defaults to `receipts.db`; [storage.py:508–520](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/clausewindow/storage.py#L508-L520) enables SQLite WAL. Backups must account for live WAL state and be restored and checked, not just copied casually. Deployment topology, monitoring, migration rollback and RPO/RTO are owner decisions.

**OWASP / security and privacy.** The API bounds individual reads ([api.py:499–539](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/clausewindow/api.py#L499-L539)), but parses the form before those checks ([api.py:604–631](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/clausewindow/api.py#L604-L631)); its request-wide guard relies on `Content-Length` ([api.py:767–799](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/clausewindow/api.py#L767-L799)). Streaming/spooling abuse without that header is an unverified risk, not a proven exploit. F04/F07 concern access and integrity. Injection detection effectiveness, secret handling outside sampled paths, retention/deletion, log exposure and dependency vulnerabilities are unverified; lower-bound dependencies and no tree lockfile do not by themselves prove a CVE.

**UI / UX / accessibility.** The [fallback page](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/clausewindow/api.py#L157-L175) has labeled file inputs, a legal disclaimer and an `aria-live` result. [api.py:181–194](https://github.com/knarayanareddy/clausewindow/blob/7adf12808884906cc85855bf9658e3a08f96e663/clausewindow/api.py#L181-L194) displays raw JSON. Keyboard, screen-reader use, error comprehension and reviewer sign-off are not demonstrated; test them rather than infer accessibility from markup.
